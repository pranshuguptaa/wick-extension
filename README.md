# Wick — live Claude token meter

> Every token Claude burns, accounted for.

A Chrome extension that shows your real-time Claude usage below the chat input —
model-aware estimates, reset countdowns, and one-click handoff to ChatGPT,
Gemini, or Grok when you hit a limit.

## Install

**[→ Download wick-v1.0.0.zip](../../releases/latest)**

Then:
1. Unzip the downloaded file
2. Open Chrome → paste `chrome://extensions` in address bar
3. Toggle on **Developer mode** (top right)
4. Click **Load unpacked** → select the unzipped folder
5. Wick appears in your toolbar instantly

Full install guide with screenshots: **usewick.online/install**

## What it shows

- Live session usage (5-hour window)
- Live weekly usage (7-day window)
- Model-aware messages left
  (Opus burns 5× faster than Haiku — Wick accounts for this)
- Countdown to reset
- One-click handoff to ChatGPT, Gemini, or Grok

## Updating

Wick checks for updates automatically every 6 hours. When a new version is
available, an amber banner appears in the popup. Click it to download the latest
zip.
